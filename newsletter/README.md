# Newsletter PDFs

Public PDFs linked from the Livable Telluride newsletter / emails. Served by
GitHub Pages, so each file is reachable at a clean, permanent URL:

```
https://livabletelluride.org/newsletter/<topic>/<descriptive-name>.pdf
```

## Convention (follow this for future PDFs)

- One folder per topic/issue: `newsletter/<topic-slug>/` (lowercase, hyphens).
- File names: lowercase, hyphens, no spaces — so URLs need no `%20` encoding.
  Date-prefix when it helps sorting (`2008-lot-y-backman-memorandum.pdf`).
- Anyone with the link can open the file (public). Don't put sensitive docs here.
- Browsers render PDFs inline — no reader install needed by recipients.
