San Miguel County Zoning

Mapbox version with a visible regional basemap beneath transparent zoning colors, an official San Miguel County boundary outline, with parcel outlines visible by default, optional roads, and a parcel development status view.

Searches uploaded driveway address points. Selecting a result zooms to the address and drops a marker with zoning, parcel, and subdivision information where matched.

Lower opacity makes roads, terrain, rivers, and labels easier to see under the zoning colors.

Green = a lot with no structure (2021–2024 building footprints). Amber lots fall under an airport (FAA) height restriction — still buildable, but density/height limited. Use the checkboxes above to remove PUD, subdivision, or protected land.
